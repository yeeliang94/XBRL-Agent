What we've changed in XBRL Agent

We've made it easier to follow a document through the application and check what it produces. You can see where work has reached, review figures and notes beside the source PDF, and compare the result with a file prepared by a person.

27 merged pull requests · Human review and final mTool validation remain required.

See what needs doing

We now have a work queue for documents. You can see which ones are waiting for setup, which are being processed and which need review.

Upload several documents, switch between saved work and return to the ones edited most recently. Preparation now finishes before setup opens. Confirm the filing details, then continue to extraction and review.

Details and sources

Preparation has its own progress view before setup. The document can then move through extraction, checks and review, with the saved history available when you return. The document list shows its current stage and the action available. You can upload several documents and switch between saved work from the sidebar. Preparation finishes before filing setup opens. You then confirm the accounting standard, Company or Group filing, units, reporting periods and statement formats. History follows the latest saved activity, including edits. Opening a document does not move it to the top.

This replaces the older benchmark workflow. We improved handling of numeric text, input formulas, repeated totals, units and numeric-note categories. Worksheet scores use the displayed concepts, periods, categories and entities, and differences are marked at the relevant cells. Choose the completed mTool file and confirm whether its figures are in RM, thousands or millions. The comparison separates matches, different values and inputs missed by AI. You can focus the worksheet on the items that need attention. Agreement scores use the relevant input figures for that worksheet. Calculated totals are excluded from the score. Agreement with a human file still needs checking against the source.

You can select which sheets to fill and resolve ambiguous destinations before the application writes to them. Keep team instructions and progress available

Administrators can save common instructions for figures and notes. Each run keeps the guidance it used, so later changes do not rewrite the instructions recorded for earlier work.

Activity shows progress, queued work and failures by worksheet or part. Saved activity and a run-specific diagnostics package help investigate problems.

Details and sources

Saved activity can be reopened after the run finishes. Run-specific diagnostics include traces and records that help investigate failures without reconstructing the whole run from memory. Shared instructions apply to extraction and review. Earlier runs retain their own copy. Activity shows preparation, extraction, review and formatting. Formatting progress names the worksheet or part, including queued work and failures. You can reopen saved activity and download a diagnostics package for that run. Credentials are redacted from the package.

Where development stands

The changes in this update are merged into the main branch. Rollout on team machines and final SSM acceptance have not been confirmed by this review.

We have not measured an overall accuracy rate or time saving for this update. Windows mTool rendering and final validation remain outstanding in the recent pull requests.

About the screenshots

Seven screenshots were captured from the local application on 12 October. It was already running, so some controls may be behind the latest merged code. The work queue contains synthetic drafts, and the review screens show an existing saved financial-statement example.

Checks reported in the latest pull request

PR #35 reports a successful production build, 6,348 passing backend tests with two fixture-related failures, and 1,594 passing frontend tests with two existing responsive-layout assertion failures. These are the PR's recorded results. We did not rerun application tests for this update.

Changes left out of the walkthrough

CLBG support was briefly added and then removed. Retired repeat-run, benchmark and scanned-PDF transcript controls are also excluded. MFRS/MPERS and Company/Group support predate this period; this update describes the improvements made to those workflows.
